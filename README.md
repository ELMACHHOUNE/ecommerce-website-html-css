# HTML CSS E-commerce Website

A modern and responsive e-commerce website built with HTML and CSS, featuring a clean design and essential e-commerce functionality.

## 🌟 Features

- Responsive design that works on all devices
- Modern and clean user interface
- Product catalog with detailed product pages
- Shopping cart functionality
- Blog section for content marketing
- Contact form for customer inquiries
- About page with company information
- User-friendly navigation

## 📁 Project Structure

```
├── index.html          # Homepage
├── shop.html          # Product catalog
├── singleProduct.html # Individual product page
├── cart.html          # Shopping cart
├── blog.html          # Blog section
├── about.html         # About page
├── contact.html       # Contact form
├── style.css          # Main stylesheet
├── script.js          # JavaScript functionality
└── images/           # Image assets
```

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/ELMACHHOUNE/ecommerce-website-html-css
```

2. Open the project folder:

```bash
cd HTML-CSS-Ecommerce-website
```

3. Open `index.html` in your web browser to view the website.
